During the internship at **AWS First Cloud Journey (FCJ)** (from **September 14, 2026** to **December 14, 2026**), the **11-week** core worklog roadmap is divided into two main phases: the first 8 weeks focus on learning core AWS concepts combined with hands-on labs across foundational service groups, and the final 3 weeks focus on designing and deploying the capstone project, **Driver Drowsiness & Distraction Detection**.

Detailed weekly logs are organized under the sections below:

**Week 1:** [Getting Started with AWS, Account Administration, AWS CLI, and Launching EC2](1.1-week1/)

**Week 2:** [Designing Amazon VPC Virtual Networks, Routing, and Network-Layer Security](1.2-week2/)

**Week 3:** [Inter-Network Connectivity with Bastion Host, VPC Peering, and Transit Gateway](1.3-week3/)

**Week 4:** [Amazon EC2 Administration, EBS Storage, Custom AMIs, and Web Server Deployment](1.4-week4/)

**Week 5:** [Elastic Load Balancing (ELB), Auto Scaling, Route 53, and CloudFront](1.5-week5/)

**Week 6:** [Data Storage with Amazon S3, EFS, and AWS Storage Gateway](1.6-week6/)

**Week 7:** [Databases on AWS with Amazon RDS, Aurora, and DynamoDB](1.7-week7/)

**Week 8:** [Security with IAM Roles, KMS, Secrets Manager; Monitoring with CloudWatch and SSM](1.8-week8/)

**Week 9:** [Designing Edge AI – AWS Serverless Architecture and Cost Estimation](1.9-week9/)

**Week 10:** [Deploying AWS Serverless Infrastructure, Finalizing Edge AI, and System Testing](1.10-week10/)

**Week 11:** [Finalizing Reports, Demo Presentation, and Cleaning Up AWS Resources](1.11-week11/)
